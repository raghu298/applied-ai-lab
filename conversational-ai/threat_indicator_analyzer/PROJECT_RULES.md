# Project Rules

1. Use `.env` file for all API keys — never hardcode secrets.
2. Keep code modular — each module has a single responsibility.
3. Add simple comments to explain non-obvious logic.
4. Include error handling for user inputs and API calls.
5. Log all analysis results to CSV for audit trail.
6. Use Streamlit for the frontend dashboard.
7. Support both rule-based and optional LLM-based analysis.
